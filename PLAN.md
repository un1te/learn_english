# План реалізації: веб-додаток для вивчення англійських слів

Онлайн-додаток, який допомагає дитині вчити англійські слова. Дитина реєструється,
додає власні слова, вчить їх картками та проходить перевірку знань. Прогрес
зберігається на бекенді для кожного користувача окремо (багатокористувацький режим).

## 1. Технологічний стек

| Шар | Технологія | Роль |
|-----|-----------|------|
| Фронт + бек | **Next.js (App Router) + TypeScript** | UI + API routes в одному проєкті |
| Стилі | **Tailwind CSS** | Адаптивний дитячий інтерфейс |
| Авторизація | **Supabase Auth** | Реєстрація/вхід за імʼям+паролем |
| База даних | **Supabase (PostgreSQL)** | Користувачі, слова, прогрес |
| i18n | **react-i18next** | Інтерфейс UA / EN |
| Озвучка | **Web Speech API** (+ fallback TTS) | Вимова слова, безкоштовно |
| Орфографія | **Free Dictionary API** | Перевірка слова + підказка |
| Картинки | **Pixabay / Openverse API** | Картинка-асоціація до слова |
| Хостинг | **Vercel** + **Supabase Cloud** | Доступ по посиланню, безкоштовно |

Усе розгортається безкоштовно (Vercel Hobby + Supabase Free).

## 2. Модель даних

**auth.users** — керується Supabase Auth (id, зашифрований пароль).
Вхід за імʼям реалізуємо через фейковий email виду `imʼя@app.local`.

**profiles**
- `id` (uuid, = auth.users.id)
- `username` (text, унікальне)
- `preferred_language` (text, 'uk' | 'en', default 'uk')
- `created_at`

**words** — особистий словник, привʼязаний до користувача
- `id` (uuid)
- `user_id` (uuid → profiles.id)
- `english` (text)
- `translation_uk` (text)
- `category` (text, nullable) — для розумних дистракторів
- `image_url` (text, nullable) — картинка-асоціація
- `is_learned` (boolean, default false)
- `correct_streak` (int, default 0)
- `created_at`, `updated_at`

Row Level Security: користувач бачить і змінює тільки свої слова.

## 3. Функціонал

### 3.1 Реєстрація / вхід
- Максимально спрощено: **імʼя + пароль** (пароль обовʼязковий, без валідації довжини на рівні UI).
- Email не питаємо — генеруємо внутрішній `username@app.local` для Supabase Auth.

### 3.2 Мова інтерфейсу
- Перемикач UA/EN у шапці, вибір зберігається в `profiles.preferred_language`.

### 3.3 Додавання слів + перевірка орфографії
- Форма: англійське слово + український переклад.
- Перевірка існування слова через Free Dictionary API.
- Якщо не знайдено — підказка "Можливо, ви мали на увазі…".
- Нове слово: `is_learned = false`, `correct_streak = 0`.

### 3.4 Режим "Вчити" (картки-перевертиші)
- Тільки невивчені слова.
- Картка: англійське слово + **картинка-асоціація** → переворот → український переклад.
- Кнопка озвучки (Web Speech API, fallback — зовнішній TTS).

### 3.5 Режим "Перевірка" (квіз)
- Два типи питань, чергуються випадково:
  1. **EN → UA:** дано англійське слово, обрати правильний український переклад.
  2. **UA → EN:** дано український переклад, обрати правильне англійське слово.
- 4 варіанти: 1 правильний + **3 близькі за змістом** (та сама категорія/частина мови,
  fallback — найсхожіші слова зі словника).
- Правильно → `correct_streak + 1`; неправильно → `correct_streak = 0`.
- `correct_streak >= 3` → `is_learned = true`.

### 3.6 Повторення (забування)
- За кнопкою/періодично бекенд випадково знімає `is_learned` з **не більше 10%**
  вивчених слів, обнуляє їхній `correct_streak` → вони знову йдуть у перевірку.

## 4. API-ендпоінти

```
POST /api/auth/register        реєстрація (імʼя+пароль)
POST /api/auth/login           вхід
GET  /api/words                слова користувача
POST /api/words                додати слово
GET  /api/words/spellcheck     перевірка орфографії + підказка
GET  /api/words/image          картинка-асоціація для слова
GET  /api/words/learn          невивчені слова для карток
GET  /api/quiz?type=en-ua|ua-en  питання квізу з розумними дистракторами
POST /api/quiz/answer          записати відповідь (оновлює streak / is_learned)
POST /api/words/forget         випадково скинути ≤10% вивчених
PUT  /api/user/language        зберегти мову інтерфейсу
```

## 5. Етапи розробки

1. Каркас Next.js (App Router, TS, Tailwind).
2. Структура проєкту + залежності (Supabase-клієнт, i18n).
3. Схема БД + SQL-міграція + RLS.
4. Авторизація (реєстрація/вхід за імʼям).
5. Словник (CRUD + орфографія + картинки).
6. Режим "Вчити" (картки + озвучка + картинка).
7. Режим "Перевірка" (квіз двох типів + дистрактори).
8. Механіка streak → learned + забування ≤10%.
9. Інтернаціоналізація UA/EN.
10. Деплой (Vercel + Supabase).

## 6. Ризики та рішення

- **Supabase Free "засинає"** після 7 днів простою — перший запит повільний, дані не втрачаються.
- **Google TTS** без офіційного API → основний варіант Web Speech API, fallback — інший вільний TTS.
- **Зовнішні API** (словник, картинки) мають ліміти → кешуємо результати, додаємо fallback.
- **Пароль min 6 символів** — обмеження Supabase Auth; за потреби замінюється власною таблицею з bcrypt.
